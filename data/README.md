# Data

The datasets in this folder are synthetic as the real data cannot be shared for confidentiality reasons. The network structure of ports, vessels, service lines and schedules as well as the types and sizes of containers are preserved.

The booking demand, vessel capacities, container stock and container stock levels have been generated for a 12 week time period.

The sample preserves the network structure and relative behaviour, but absolute results are not comparable to those reported in the thesis.
